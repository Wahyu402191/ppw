Pengantar Web Mining

Web Mining merupakan proses penerapan teknik data mining untuk menemukan informasi dan pola yang bermanfaat dari data yang terdapat di World Wide Web.

Perkembangan internet menyebabkan jumlah data yang tersedia di dalam web semakin besar. Data tersebut dapat berupa halaman web, dokumen, gambar, struktur hubungan antarhalaman, maupun aktivitas pengguna.

Web Mining digunakan untuk mengolah dan menganalisis data tersebut sehingga dapat menghasilkan informasi yang berguna bagi pengguna maupun organisasi.

Secara umum, Web Mining dapat dibagi menjadi tiga jenis, yaitu Web Content Mining, Web Structure Mining, dan Web Usage Mining.
